Sou desenvolvedor com experiência em interfaces web, automações, integração de APIs e TI corporativa. Trabalho com JavaScript, TypeScript e React para construir interfaces, e com Node.js e Python em serviços e integrações.

Minha trajetória inclui desenvolvimento e infraestrutura na DSOP Educação Financeira, tratamento de dados para projetos de auditoria na EY e atuação em tecnologia na NAOS Brasil. Essas experiências contribuem para conectar o desenvolvimento às necessidades dos usuários e dos processos de negócio.

Nos meus projetos, desenvolvo soluções de atendimento conversacional com inteligência artificial, ferramentas para processos internos e aplicações web acadêmicas.

Busco oportunidades em desenvolvimento frontend e full stack, com interesse em usabilidade, organização de código e integração de sistemas.

Fora da tecnologia, gosto de praticar esportes, especialmente ciclismo.
