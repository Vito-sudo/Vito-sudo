## Projetos em destaque

### MagicBot — Atendimento e automação conversacional

Projeto em desenvolvimento para atendimento pelo WhatsApp, com integração de inteligência artificial, APIs e persistência de conversas.

**Contribuições técnicas:**
- Desenvolvimento de serviços em JavaScript e Node.js.
- Integração com WhatsApp por meio de Baileys.
- Persistência de conversas e eventos em MySQL.
- Construção de fluxos de cadastro e reserva com estados de atendimento.
- Desenvolvimento de integração com a API Conexa.
- Organização de serviços de agentes, roteamento e atendimento.

**Tecnologias:** Node.js, JavaScript, MySQL, APIs e inteligência artificial.

### Sistema de Rateio de Faturas

Aplicação voltada à organização e ao rateio de faturas no contexto corporativo.

**Contribuições técnicas:**
- Desenvolvimento de interface com React e Vite.
- Construção de API com Python e FastAPI.
- Separação entre frontend e backend.
- Configuração da comunicação entre interface e API.

**Tecnologias:** React, Vite, Python e FastAPI.

### Aqui e Agora Pet — Protótipo acadêmico

Projeto de adoção responsável com interface web, Pet Match e triagem virtual.

**Contribuições técnicas:**
- Organização de HTML, CSS e JavaScript em arquivos separados.
- Construção de interfaces responsivas e validação de formulários.
- Desenvolvimento de triagem conversacional e resumo para atendimento humano.
- Implementação de backend demonstrativo em Node.js.

**Tecnologias:** HTML, CSS, JavaScript e Node.js.

> Protótipo acadêmico com recursos demonstrativos de cadastro e doação.

[Explorar repositório](https://github.com/Vito-sudo/Ong-Pet)

### Central de Suporte Corporativo

Interface web para organizar canais e orientações de suporte em TI.

**Contribuições técnicas:**
- Estruturação da navegação e dos conteúdos de atendimento.
- Desenvolvimento de interface com HTML, CSS e JavaScript.
- Organização de recursos visuais e atalhos para canais de suporte.

**Tecnologias:** HTML, CSS e JavaScript.

### ONG Aqui e Agora
